# Hermes ESRA roadmap — historical implementation

Status: 15 September 2026

This repository is retained as the historical Hermes-specific ESRA implementation. It contains useful early skills, fixtures, recommendation-only trigger logic, and design ideas, but it is no longer a competing runtime implementation.

Active autonomous development now lives in the universal [`rrpauls/esra-agents`](https://github.com/rrpauls/esra-agents) repository:

- [Autonomous ESRA roadmap](https://github.com/rrpauls/esra-agents/blob/main/docs/AUTONOMOUS_ROADMAP.md)
- [Autonomous host gate](https://github.com/rrpauls/esra-agents/blob/main/docs/AUTONOMOUS_HOST_GATE.md)
- [Hermes native adapter](https://github.com/rrpauls/esra-agents/tree/main/adapters/hermes)

No second Hermes runtime will be maintained here. Confirmed useful fixtures and ideas may be migrated into `esra-agents`; this repository remains available for provenance and comparison.
